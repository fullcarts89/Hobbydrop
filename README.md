# HobbyDrop

A community-powered marketplace where hobbyists sell a whole collection of gear as one shareable drop.

**Status: Phase 0 (product and technical discovery). No application code yet.** Implementation starts once the founder approves the scope and architecture in [`docs/discovery/05-roadmap-risks-and-decisions.md`](docs/discovery/05-roadmap-risks-and-decisions.md).
